# Estudos em Python

![Python](https://img.shields.io/badge/Python-3.x-3776AB?style=flat&logo=python&logoColor=white)
![Status](https://img.shields.io/badge/status-em%20andamento-yellow)

Repositório dedicado ao armazenamento de exercícios, anotações e projetos desenvolvidos ao longo dos meus estudos de Python.

## Sobre

O conteúdo deste repositório acompanha meu progresso no aprendizado da linguagem, com foco na prática de conceitos fundamentais e no desenvolvimento de pequenos projetos. O material está em constante atualização à medida que avanço nos estudos.

## Base de estudo

Os estudos têm como referência principal o livro *Curso Intensivo de Python*, de Eric Matthes.

## Objetivos

- Consolidar os fundamentos da linguagem Python
- Praticar a resolução de problemas por meio de exercícios
- Desenvolver pequenos projetos para aplicar os conceitos aprendidos
- Acompanhar e registrar minha evolução ao longo do tempo

## Estrutura

Os arquivos estão organizados conforme o progresso dos estudos e podem incluir:

- Exercícios práticos
- Anotações
- Pequenos projetos
- Testes de código

## Tecnologias

- Python 3.x

## Como executar

Clone o repositório e execute os arquivos desejados:

```bash
git clone https://github.com/maiconcutrim/pythoncrashcourse.git
cd pythoncrashcourse
```
